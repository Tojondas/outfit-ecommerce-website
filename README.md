
# 🛍️ Outfit – E-Commerce Website

A responsive frontend e-commerce website originally developed as my **Diploma Minor Project** using HTML5, CSS3, and Vanilla JavaScript.

The project was later revisited to fix existing issues, improve the user interface, and enhance the overall functionality and responsiveness.

---

## 📌 About the Project

**Outfit** is a frontend-based e-commerce website designed to provide a simple and user-friendly online shopping experience.

The project was originally developed during my Diploma as a **Minor Project** to gain practical experience in web development and understand the fundamentals of building an e-commerce website.

After revisiting the project, I made several improvements and fixes to make the website more polished, responsive, and functional.

---

## ✨ Features

- 📱 Fully Responsive Design
- 🛍️ Product Browsing
- 🛒 Add to Cart Functionality
- ➕ Increase / Decrease Product Quantity
- 💰 Dynamic Cart Total
- 📧 Newsletter Subscription Interface
- 🎨 Clean and Modern UI
- ⚡ Interactive Elements using JavaScript
- 🌐 Multiple Pages

---

## 📄 Pages

- `index.html` – Home Page
- `shop.html` – Shop / Product Page
- `cart.html` – Shopping Cart Page

---

## 🛠️ Technologies Used

- **HTML5** – Structure and content
- **CSS3** – Styling, layout, and responsive design
- **JavaScript** – Interactivity and cart functionality
